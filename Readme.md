This directory contains three folders: 
1. Loglik_approx:  R code to reproduce likelihood approximation
2. Sim1D_examples: R code to reproduce 1D toy examples 
3. Sim10_20D_examples: R code to reproduce high-dimensional examples

The package file needs to be installed locally in R before running the code or ipynb notebook. Positron software can be used to run these notebooks. 

```{r}
# To install the package use
devtools::install_github("pulongma/ResTree")

```
